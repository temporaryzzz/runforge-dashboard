# AI usage log

## Инструмент и модели

- Инструмент: GitHub Copilot в VS Code (Copilot SDK).
- Модели, использованные в ходе работы: `mai-code-2-flash` на начальном этапе и `gpt-6-luna` после переключения модели.

## Переданный контекст

AI получил краткое описание тестового задания и выбранный стек: TypeScript, React, Tailwind CSS, Vitest, React Testing Library и JSON Server. Для реализации и исправлений предоставлялся текущий код проекта, в частности тип `Run`, компоненты списка и карточки, mock-данные и сообщения об ошибках тестов.

## Примеры небольших запросов

1. **Mock-данные:** «Добавь в `db.json` 10 записей по заданной модели `Run`, используя все четыре статуса».
    - AI подготовил mock-записи для JSON Server.
    - Результат проверен на корректность JSON, количество записей и допустимые статусы.

2. **Логи карточки:** «Добавь отображение `logs` в раскрытые подробности карточки запуска, ограничь максимальную высоту, добавь скролл при переполнении».
    - AI вывел логи отдельным нумерованным списком внутри раскрываемой части карточки.
    - Для записи без логов позже добавил нейтральное сообщение.

## Ошибка AI и исправление

При написании теста открытия подробностей AI добавил проверку `getByText('Branch')`. Тест завершился ошибкой: текст `Branch` присутствовал в DOM нескольких карточек, включая свёрнутую карточку, и запрос находил несколько совпадений.

Далее я скорректировал код: вместо текста ветки тест проверяет уникальный заголовок `Logs`, который есть только у одной из двух записей и конкретные строки логов.
